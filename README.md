# 🛒 Salla → Telegram n8n Workflow

قالب **n8n Workflow** يتيح لك ربط متجرك في **سلة (Salla)** مع **تيليجرام**، بحيث يتم إرسال إشعار تلقائي إلى تيليجرام عند **إضافة منتج جديد** إلى المتجر.

---

## ✨ المميزات

* 🔔 إشعار فوري عند إنشاء منتج جديد
* 📦 عرض اسم المنتج، السعر، والكمية
* 🔗 زر مباشر لعرض المنتج في المتجر
* 🔐 حماية Webhook باستخدام Secret Header
* ⚙️ سهل التخصيص والتعديل
---

## 🧩 المتطلبات

قبل البدء تأكد من توفر:

* حساب **n8n** (Self-hosted أو Cloud)
* متجر على **سلة (Salla)**
* بوت **Telegram**
* قناة أو محادثة تيليجرام لاستقبال الرسائل
---

## 📥 طريقة التثبيت

### 1. استيراد الـ Workflow إلى n8n

1. افتح n8n
2. من القائمة اختر **Import Workflow**
3. ألصق محتوى ملف `workflow.json`
4. احفظ الـ Workflow

---

### 2. إعداد Webhook في سلة

1. ادخل إلى لوحة تحكم سلة
2. انتقل إلى:

   ```
   الكل > أدوات المطور > إضافة Webhook جديد
   ```
3. أضف Webhook جديد:

   * **إسم الحدث:** اختر أي اسم يناسبك
   * **نوع الحدث:** اختر "تم إنشاء منتج"
   * **نسحة إصدار الإشعار المرسل:** النسخة V2
   * **رابط الحدث:** ضع رابط Webhook الذي أنشئته داخل n8n.


     ```
     https://YOUR-N8N-DOMAIN/webhook/salla-webhook
     ```
4. أضف Header:

   * **Key:** `x-salla-secret`
   * **Value:** قيمة سرية من اختيارك (مثال: `my_super_secret`)

---

### 3. تحديث Secret داخل n8n (مهم جدًا)

داخل الـ Workflow:

1. افتح عقدة **Header Validation**
2. غيّر القيمة:

   ```text
   MY_SECRET_KEY
   ```

   إلى نفس القيمة التي وضعتها في سلة.

⚠️ في حال عدم التطابق، سيتم تجاهل الطلب ولن تُرسل أي رسالة.

---

### 4. إعداد Telegram Credentials

1. أنشئ Bot عبر **@BotFather**
2. انسخ **Bot Token**
3. في n8n:

   * اذهب إلى **Credentials**
   * أنشئ **Telegram API**
   * الصق الـ Token
4. اربط الـ Credentials بعقدة **Send a text message**

---

## 🧪 الاختبار

1. أنشئ منتجًا جديدًا في متجر سلة
2. تأكد من:

   * وصول رسالة إلى تيليجرام
   * ظهور اسم المنتج والسعر والكمية
   * عمل زر "عرض المنتج" بشكل صحيح

---

## 🛠️ التخصيص

يمكنك بسهولة:

* تغيير نص الرسالة من عقدة **Code in JavaScript**
* إضافة أحداث أخرى من سلة (مثل تحديث المنتج)
* إرسال الرسائل إلى:

  * مجموعة
  * قناة
  * مستخدم فردي

---

## 🔐 ملاحظات أمنية

* ❗ لا تشارك Workflow يحتوي على:

  * Secrets حقيقية
  * Tokens
  * Webhook URLs فعالة
* دائمًا استخدم Secret مختلف لكل مشروع
